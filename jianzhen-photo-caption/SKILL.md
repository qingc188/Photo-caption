# 简媜文风摄影配文

内置简媜（台湾散文家，风格关键词：奇崛、瑰丽、深情、清冷、禅意、文白交融）的 1521 条公开书摘/名句语料库（90 书目分组，每条带《书名》（篇名）出处），完成两件事：

1. **照片 → 检索最相关原文摘句**（默认 25 条）
2. **照片 → 模仿简媜文风生成原创配文**（散文×5、现代诗×5、短句×5）

## 资源

- 语料库：`references/corpus/`（85 个 md 文件 + `00_书目汇总索引.md` 按书聚合）
- 检索脚本：`scripts/search_corpus.py`
- 文风四层知识：`references/style_guide.md`（**生成配文前必读**）
- 交付口径与质检：`references/delivery-format.md`
- 主题索引：`references/topic-index.md`

## 工作流

### 步骤 1：解析照片
读取用户照片（必要时先缩放/读图），提取结构化要素：
- 画面意象：主体物、光线、色彩、季节/时段、空间氛围
- 情绪基调：清冷/温热/怅惘/孤寂/静谧/温柔/悲欣…
- 场景类型：自然/城市/人物/静物/人文

### 步骤 2：检索原文
运行检索脚本，关键词从"画面意象+情绪基调"提取：

```
python scripts/search_corpus.py 树 午后 光影 --top 40
python scripts/search_corpus.py 空椅 等待 独坐 --strict --top 20
```

- 默认匹配任一关键词；`--strict` 匹配全部；`--top N` 控制返回上限
- 命中不足时扩展意象近邻词（雾→云/朦胧/水汽；树→荫/影/枯叶/枝/凉）
- 也可直接 Grep `references/corpus/` 按需检索

### 步骤 3：精选 25 条原文
按"画面意象+情绪基调"从命中结果中精选 25 条：
- 覆盖维度：情绪、氛围、意境、场景、描写 各取若干，避免同书扎堆
- 冷门句子优先补足；可含上下句多句片段、氛围情绪相近的句子
- 每条输出：原文 + 《书名》（篇名）+ 一句话分析理由（对应照片的哪一点）
- **禁止杜撰出处**；出处模糊的句子标注"简媜（散篇）"

### 步骤 4：生成 15 条原创配文
先读 `references/style_guide.md` 与 `references/delivery-format.md`，以步骤 3 命中的原文为文风锚点，生成：
- 散文 ×5（约 150–300 字）
- 现代诗 ×5（约 8–15 行）
- 短句 ×5（一句话级）

硬约束（内化自 style_guide）：
- 长短句交错出呼吸感：长句可绵延十余字不换气，紧跟二、三字短句顿住；现代诗不得全用短句堆砌
- 物我交融，主语在人/物/自然间自由滑移；保留对"你"的倾诉感/书信感
- 情绪落在具体物象上（一盏灯、一阵风、一片霜），不空洞抒情
- 克制而深情，越痛写得越淡；禁口号、禁排比轰炸、禁总结陈词、禁网络热词
- 每个比喻都要"贴"照片的真实意象
- **原创配文禁止挪用语料原句**：可化用简媜的意象、句式节奏、用词逻辑（如叠词、文白夹杂、物我置换），但每个句子必须全新创作，不得整句或半句摘抄语料库原文

### 步骤 5：交付与征询
- 25 条原文 + 15 条配文**全部直接输出在对话中，不落盘**
- 交付后主动询问：满不满意？是否需要再生成一轮完全不重复的供选择？
- 可询问用户偏好调子（清冷孤独 / 人间烟火 / 俏皮少女气）再微调

## 版权口径

只收录公开书摘/名句/单篇节选，不转录全集。所有句子保留《书名》（篇名）出处标注。

# 简媜文库 · 主题/情绪索引

> 用途：照片检索时，从画面意象与情绪基调 → 命中本索引 → 定位 corpus 中的相关摘录。
> 检索逻辑：照片主题 → 主题标签 → 扩展意象近邻（如"雾中的山"→山/林/云/朦胧/独）→ 在 corpus 全库中按关键词+主题标签匹配。
> 收录范围：与 corpus 三个摘录文件配套，可随库扩充。

### 思念 / 想念
- 如果问我思念多重，不重的，像一座秋山的落叶。——《私房书》
- 想人想的厉害的时候，也是淡淡的。像饿了许多日的人闻到炊烟，但知道不是自家的。
- 我不是一个会哭哭啼啼挽留别人的人……我只会很笨拙地把思念埋在发间，让野风吹拂，雷雨浸润，看着它恣意抽长，直到承受不了，一把剪去满头的思念，然后在日渐冷清的年华里，看它重新纠缠。——《旧情复燃》
- 你所在之处，是我不得不思念的天涯海角。——《天涯海角》
- 思念是生者的事，愿意记得的，会在红尘的某个角落，回忆属于他们的甜美时光，在心里清楚一个空位，静静与他对话。——《微晕的树林》

### 离别 / 相忘 / 送行
- 秋天把旧叶子揉掉了，你要听新故事吗。静静的河水睁着眼睛，笑着说：总有回家的人，总有离岸的船。——《浮舟》
- 无须更多言语，我必与你相忘于江湖，以沧桑为饮，年华果腹，岁月做衣锦华服，于百转千回后，悄然转身，然后，离去。
- 没有狂歌当哭的勇气，却在倒地时明心见性，瞥见万里风沙之上，有人沉腕拨镫，疾书一行字："相忘于江湖"。

### 孤独 / 独处

### 记忆 / 时光哲学 / 荣枯之道

- 时间，从来不善于保存人情。——《空灵》
- 我们对记忆了解多少？……我相信那是终年叆叆的云梦大泽，看起来像风景明信片般简单明了，当你试图跨越，却发现渺茫无边，而你贫穷得连半截浮木都没有。——《四月裂帛》
- 遇合之人、离散之事，同时是因也同时是果；人在其间走走停停，做个认真的旅行者罢了。——《四月裂帛》
- 在繁茂的景象之中，似乎隐藏另一层暧昧：是将离未离，将熄未灭的兴寄。——《空灵》
- 那时，春天只有三分熟，我在梦中独自行走。——《旧情复燃》

### 生活小品 / 人间烟火 / 微物之美

- 到了这年纪，还有谁，值得我们坐下来，脑中浮出影像，安安静静地写一封长信给他？写信，除了家书，越美的信越要趁年轻。——《我为你洒下月光》

- 茫茫人海藏着看不见的线索，那命中注定要经历情事的两人，无须繁复的铺排，于满堂人群之中，一见钟情。——《我为你洒下月光》

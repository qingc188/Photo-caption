# 简媜文风指南（配文生成引擎 · 风格知识库）

简媜（1961—），台湾宜兰人，台大中文系毕业，当代散文名家，台湾文坛无争议的实力派女作家。
**风格关键词**：奇崛、瑰丽、深情、清冷、禅意、少女气、文言白话交融、壮烈与温柔的张力。

本指南是「仿写引擎」的核心约束清单，分四层：词汇、句式、意象、语调。生成配文前必须通读并逐条对照。

---

## 一、词汇层

1. **叠字叠词**：潺潺、脉脉、霏霏、冉冉、昏昏、寂寂、密密——用叠词制造音韵与绵延感，但不滥用。
2. **古典语汇 / 文白夹杂**：兮、其、乃、弗、宁、焉等文言虚词偶入白话；「你甚美丽」这类文白交错的句式是标志性特征。
3. **奇崛动词**：拒绝平庸的「走/看/想」，偏好「游走、逶迤、泅渡、俯身、掬起、攀折、嵌、漏、倾泻」；常用非常规动宾搭配（如「把心事种进苔痕里」）。
4. **色彩词两极化**：极浓烈与极清淡并存——胭脂、朱红、银闪、墨、霜白、青灰；颜色往往与人情、时间绑定（「银闪闪的地方」「胭脂盆地」）。
5. **闽南语/方言点缀**：乡土与童年题材中偶现（如「月娘」「眠床」），制造亲切与土气之美。
6. **身体与器物词**：骨、发、眼、掌、杯、信、绳、门、窗——具体可感，不空泛。

## 二、句式层

1. **长短句强烈交错**：一句绵延十几字不换气，紧跟一个两三字的短句顿住，形成呼吸感。
2. **物我交融**：人与物互相置换——「我」可以是风、树、月；物有人的情感与记忆；主语在人/物/自然之间自由滑移。
3. **呼语与第二人称**：频繁对「你」「月娘」「故乡」「季节」说话，带书信感与倾诉感（简媜大量文本是「致你」体）。
4. **设问与反问**：自问自答，叩问时间与命运，但不求答案。
5. **省略主语 / 无主语起笔**：句子直接从意象起笔，如「窗外，雪正下到第三年。」
6. **排比与复沓**：叠句回环，情绪逐层推高；但避免机械对仗。
7. **时间揉碎**：过去、现在、未来并置，记忆与当下叠影。

## 三、意象层（高频意象谱系）

- **水族**：水、雨、泪、泉、溪、海、霜、雪
- **天体与光**：月、星、云、光、灯火、银
- **植物**：花（杜鹃、朱槿、百合、莲）、树（榕树、椰林）、藤、叶、苔
- **时间**：晨昏、四季、夜、青春、暮年、节气
- **空间**：山、林、村落、都市、窗、庭院、巷、坟茔
- **梦**：梦游、梦境、遗忘、故人
- **器物**：信、杯、书、门、绳、伞

这些意象常被赋予**人格或神性**（月娘、花神），自然拟人化程度极高——树会说话，月有悲喜。

## 四、语调层

1. **深情而不腻**：浓烈情感用克制、疏离的句子表达，不直白抒情；越痛越写得淡。
2. **清冷而不寒**：冷冽意象下藏着温热；冷是外壳，热是内核。
3. **禅意而不玄**：人生哲思落回具体物象（一盏灯、一段绳、一阵风），不空谈玄理。
4. **少女气与苍凉并存**：既有天真烂漫、俏皮的比喻，又有对时间的锐利觉察。
5. **壮烈与温柔的张力**：文字可以「杀伐征讨」，也可以「低眉敛目」；同一段里可陡转。

## 风格禁忌（去 AI 味清单）

- 禁止整齐对仗、口号式金句、排比轰炸。
- 禁止成语堆砌与「岁月静好」式陈词。
- 禁止现代网络用语、热词、梗。
- 禁止每句都以「啊 / 呀 / 哦」感叹收尾。
- 禁止空洞抒情——情绪必须落在具体物象上。

## 生成检查清单（每条配文提交前逐项自检）

- [ ] 是否至少有一个非常规动词或动宾搭配？
- [ ] 是否具备长短句交错的呼吸节奏？
- [ ] 是否有人 / 物 / 自然的交融或置换？
- [ ] 是否有具象物象落地（而非只有抽象情绪）？
- [ ] 是否克制（不直白喊「我很孤独」，而是写一盏灯、一阵风、一片霜）？
- [ ] 是否保留简媜式「对你说」的倾诉感 / 书信感？
- [ ] 是否与照片的画面意象、情绪基调呼应（不跑题）？

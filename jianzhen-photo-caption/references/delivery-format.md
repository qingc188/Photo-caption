# 交付口径与质检（jianzhen-photo-caption）

> 用途：给定一组摄影照片，产出「25 条最相关简媜原句摘抄 + 15 条原创配文」。
> 使用前必读：`style_guide.md`（文风四层知识）、`topic-index.md`（主题→锚点句）。
> 检索入口：`corpus/00_书目汇总索引.md`（按书/篇浏览）、`corpus/00_摘录_*.md`（全文检索）、`scripts/search_corpus.py`（关键词检索）。

## 一、输入解析（照片 → 结构化要素）

```
对每张照片提取：
- 画面意象：主体物、光线、色彩、季节/时段、空间氛围（如"雾中的山""窗边的旧物""雨夜的灯"）
- 情绪基调：清冷/温热/怅惘/旷达/孤寂/热烈/静谧/梦幻/温柔/飒烈/幽默/悲欣（见 topic-index.md）
- 场景类型：自然/城市/人物/静物/人文…
```

## 二、检索锚定（功能①：25 条最相关原文）

```
检索规则：
1. 用「画面意象 + 情绪基调」在 topic-index.md 定位主题（如"雾中独行"→ 山/林/云/独/雨）
2. 运行 scripts/search_corpus.py 关键词检索，或直接 Grep references/corpus/
3. 覆盖维度：情绪、氛围、意境、场景、描写 各取若干，避免同书扎堆
4. 冷门句子优先：若首轮命中不足，扩展意象近邻词（雾→云/朦胧/岚/水汽；树→荫/影/枯叶/枝/凉）
5. 可含上下句多句片段、氛围情绪相近的句子；每条尽量带明确出处
输出：每条摘抄 = 原文 + 《书名》（篇名）+ 分析理由（与照片画面的对应点）
禁止杜撰出处；出处模糊的句子标注"简媜（散篇）"
```

## 三、风格生成（功能②：15 条原创配文）

```
产出结构（用户锁定）：
- 散文 ×5（约 150–300 字）
- 现代诗 ×5（约 8–15 行）
- 短句 ×5（一句话级）

生成约束（内化 style_guide.md）：
1. 词汇：多用简媜高频词（月光/窗/尘埃/旧/江湖/尘世/渡/软/烬/斑剥/静定…），禁用网络流行词
2. 句式：长短交错的呼吸感——长句可绵延十余字不换气，偶用二、三字短句起势顿住（"于是。""这样也好。"）；现代诗须长短句结合，禁止全篇短句堆砌
3. 意象：从照片真实意象出发，做"物→情"的转写，不堆砌辞藻；每一个比喻都要"贴"
4. 语调：既清冷自持又温热悲悯，克制而深情，拒绝口号与直白抒情
5. 去 AI 味：禁"首先/其次/此外"、禁排比句阵列、禁总结陈词式结尾、禁华丽词藻堆砌
6. **禁止挪用原文**：原创配文不得整句/半句摘抄语料库句子，只可化用简媜的意象、句式节奏与用词逻辑，句子须全新创作

以检索命中的 25 条原文为 few-shot 文风锚点（功能①与功能②共享同一检索结果）。
```

## 四、交付与征询

```
- 25 条原文 + 15 条配文全部直接输出在对话中，不落盘
- 交付后主动询问：满不满意？是否需要再生成一轮完全不重复的供选择？
- 可询问用户偏好调子（清冷孤独 / 人间烟火 / 俏皮少女气）再微调
```

## 五、质检清单（交付前逐项核对）

```
□ 25 条摘抄均来自真实语料，出处准确，无杜撰
□ 15 条配文与照片画面意象呼应（每张照片都能对号）
□ 散文字数 150–300、现代诗 8–15 行、短句一句话级
□ 文风符合 style_guide 四层约束，无明显 AI 味
□ 15 条内无自我重复，主题分布有层次
```

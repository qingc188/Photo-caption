# 简媜摘录库 · 番茄小说《水问》化音部分补（六十一）

> 来源：番茄小说《简媜三十年散文之路》免费章节《水问》(8)（fanqienovel.com/reader/6948654685360229384），第六辑化音各篇佳句，按与既有语料去重后收录。

## 《水问》——凤凰季节 / 行路的幸福

- 我们开始想象，在我们的生命尚未降临之前，必有一枚奇异的种子被那位最高的存在暗暗地嵌入我们汩动的骨血之中。——《水问》（凤凰季节·种子）
- 允诺在我们逐渐牢固的筋骨血肉里，那枚种子不复只是一枚，要化成万千碎末，堪供昂昂七尺身躯吞咽吸取。这咀嚼不尽的所谓初生的赐福，当是一霎清明、一肩慷慨、一身血泪，以及一种无所逃遁的永世的追寻。——《水问》（凤凰季节·种子）
- 如果陨落的流程中，那儿有一布天色，一阵熏风相迎，也许落身之处正是灿烂的花房，便容身于绿草春席的襁褓之中被喂以荣华富贵的人间粮食。——《水问》（凤凰季节）
- "横在你的睡眠和清醒之间的距离才是最大的距离，横在你的行为和你的欲望之间的空间才是最大的空间。"也许跋涉的意义在日渐强壮的年龄里也日渐晦涩！那么睡与醒之间的距离也广袤得一如无边无际的洪荒。在时间之蹄的重重践踏下，谁又能免于一身瘀伤？——《水问》（行路的幸福）
- 当我下定决心检点生之痕迹时，我的哀恸无法再编译，我感到天地君亲师只有一个虚设的名词，只不过无止尽地鞭打我未强壮的沙岸而不是赐我活水浩瀚的海洋。——《水问》（行路的幸福）
- 如果在我们所诞生的岛屿上，生命的含义被编成一首歌或一个谜的话，除了我们的痛苦，还有什么能携带这歌声，解开这谜底？——《水问》（行路的幸福）
- 那枚奇异的种子只有在极难堪的咀嚼过程后，方能化成一霎清明。——《水问》（行路的幸福）
- 成为西西弗斯或成为那粒滚石，都是一趟人世来去，而所谓"行路的幸福"应当只有西西弗斯那双瘏困的双脚方能了悟。——《水问》（行路的幸福）

## 《水问》——栖 / 化 / 心灵之河 / 不忍问归期

- 生命的理由并非只将自己栖居在无尘无沙的地域，而更严肃的行动乃是眷顾前尘之后，又回到红尘的中心成就一肩慷慨，所谓对人世的不忍。——《水问》（栖）
- 火浴之后，那虚脱是生命最高层次的一种幸福。——《水问》（化）
- 我总是孱弱，干渴于每一次辣日的季节。我的河床堆积着现实的泥沙，我的河岸承受不住理想的幻灭而崩垮，我恐怕已不是孕育地粮的江河，而只是濯足的淤水。——《水问》（心灵之河）
- 你那奇特的如水奔的嗓音灌溉我龟裂的河床，及我焦狠了的裸石及我岸上噤闭的蓓蕾及我蜷缩的树叶……我重新有了蓊绿的肤色。——《水问》（心灵之河）
- 这样一个沉寂的雨夜，我来到总图写稿。灯，依旧亮了一室，一盏盏要伴人静读。——《水问》（不忍问归期）
- 我的思绪像一只冲破樊笼的夜莺，越过黑夜的山谷，要飞回情感的森林。——《水问》（不忍问归期）
- 我们交错的不是开在天空中的花朵，而是土壤里的盘根。——《水问》（不忍问归期）

## 《水问》——受伤的小鸟要袖藏 / 有一种花 / 水经注

- 每一种动物都有自己疗伤的本能，就举小鸟为例吧，受伤的小鸟会自己去找一个隐秘的洞，用唾液将伤口舐净，然后也不吃也不喝，静静地敛羽睡眠，睡到春天来唤醒它。——《水问》（受伤的小鸟要袖藏）
- 小鸟一旦伤愈，膀子也坚实，春的原野那么宽阔，水田漠漠，小鸟忘了伤痛，奋力向天空鼓翅，"扑""扑""扑扑"，小鸟要飞很长的路。——《水问》（受伤的小鸟要袖藏）
- 是不是有一种花，四季都香？是不是有一种花，日夜都香？是不是有一种花，自有自的香法，也不顾春夏，也不管霜雪，不论是翩翩儒士或一介白丁，都可以掬一捧清香回去？——《水问》（有一种花）
- 永恒不是一种"厮守"，而是"超越"；越过日月黄昏的差距，越过千山万水的阻绝，去关怀与会合。——《水问》（有一种花）
- 我想，是结束的时候了。水若已枯，留着一条干燥的河床做什么呢？一个人用她一生的眼泪与血水也代替不了河流的奔咽，那么去把河床铲平吧！让它变成一条路，路是无尽的方向。——《水问》（水经注）
- 人的一生只能浪漫一次，最初也是最后，哪怕是对同一个人，黄金时代只允许一次，破镜不能重圆。——《水问》（水经注）
- 我们在少年的野旷中完成自戕与戕人的爱，我们歃血为盟，我们伤痕累累，我们的祭典完成了，应该绝版。——《水问》（水经注）
- 爱是一门艺术，需要天赋也需要学习，从你那里，我得到严格的训练；从我这儿，你亦应理解相待的奥秘。——《水问》（水经注）
- 路是无尽的方向，让我们在心里自誓，不要回顾。——《水问》（水经注）
